Counted Loops



A loop repeats a block by jumping backward to a label. Keep a counter, test it before entering, and move it toward a stopping value. Testing first allows a zero count to run the body zero times.

mov rax, 0
mov rcx, 3
.loop:
cmp rcx, 0
je .done
add rax, 2
dec rcx
jmp .loop
.done:
Three iterations add 2 three times. At zero, the loop exits before the next addition.

A counted loop needs initialization, a stopping test and a counter update.
